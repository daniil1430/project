5. Импорт банковской выписки
Паттерн: Фабричный метод (Factory Method)
Импорт банковской выписки: формат определяется по содержимому файла, а не по расширению (расширение может не совпадать с содержимым), после чего создаётся соответствующий разборщик. Форматы (CSV, XML, JSON) регистрируются извне, добавление нового не затрагивает код импорта (т.е. понадобится сущность - реестр парсеров). Неизвестный формат - внятная ошибка, а не падение. Функциональность требуется реализовать на самом деле, для парсинга использовать встроенные в стандартную библиотеку средства (если есть, как в python) или любые сторонние библиотеки.
Подсказки по языку: Python - словарь и декоратор-регистратор над классом разборщика.
