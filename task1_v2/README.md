Максимальная сумма подотрезка. В массиве целых чисел, среди которых есть отрицательные, найти непрерывный отрезок с наибольшей суммой. Три способа: перебрать все пары «начало, конец» и для каждой считать сумму отдельным циклом; перебрать все начала и, сдвигая конец вправо, накапливать сумму без внутреннего цикла; за один проход вести текущую сумму, прибавляя очередной элемент и обнуляя её, как только она стала отрицательной, и держать максимум из всех виденных значений.
